# 釣水球

夜市的紙鉤釣水球：一根釣竿垂下釣線，線端的小紙圈套住水球頸部、撈上水面就得分。60 秒內釣到 8 顆過關。

## 玩法

1. 左右拖曳池塘（或按 ◀▶ 鍵）移動釣竿。
2. 按住「沉下」讓紙圈下沉；套中水球頸部後放開即自動收竿撈起。
3. 下太深會弄破紙圈（記一次 miss）；時間內釣到目標顆數即過關。

## 操作

- **滑鼠／觸控**：在池塘上拖曳移動釣竿；按住「沉下」下沉、放開收竿。
- **鍵盤**：`◀`/`▶` 移動釣竿；「開始」開始／重玩。
- 時限 60 秒、目標 8 顆（可在 `game.js` 設定調整）。

## 技術

- `game.js`：純函式邏輯（水球漂流、釣竿移動、下沉／套頸判定、計時、過關）— 可單元測試。
- `app.js`：Canvas 渲染與拖曳／鍵盤互動。
- `audio.js`：Web Audio 即時合成音效，無第三方音檔。
- 最佳顆數存 `/api/kv/pg-diaoshui-best`（Playgrounds KV）；無 KV 環境照玩。
